# 運用ガイド(移転しました)

slnmix は petari と 1 つになり、tazuna に統合されました(tazuna 0.15.0)。この文書は tazuna のリポジトリへ移りました。

→ <https://github.com/ishibashi0112/tazuna/blob/main/docs/WORKFLOW.md>

コマンドは `npx slnmix` → `npx tazuna pack`、`npx slnmix init` → `npx tazuna init`、
`npx slnmix build` → `npx tazuna build`、`npx petari` → `npx tazuna` に変わりました(オプションは同じ名前)。
